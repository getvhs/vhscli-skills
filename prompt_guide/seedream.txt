================================================================================
01  GENERAL PRINCIPLES
================================================================================

Seedream 4.5 and 4.0 support text-to-image generation, image editing, reference-based
generation, and multi-image creation. Compared to Seedream 3.0, Seedream 4.5 and 4.0 have
stronger text prompt understanding and no longer produce washed-out images. Concise and
precise prompts generally outperform long, ornate descriptions.


1.1  Describe the Scene with Natural Language
----------------------------------------------
Use coherent natural language to describe Subject + Action + Environment. If aesthetics
matter, include descriptors of style, color, lighting, or composition.

  GOOD: "A girl in a lavish dress walking under a parasol along a tree-lined path, in the
         style of a Monet oil painting."
  BAD:  "Girl, umbrella, tree-lined street, oil painting texture."


1.2  Specify the Application Scenario
--------------------------------------
If you have a specific use case, explicitly state the image purpose and type.

  GOOD: "Design a logo for a gaming company. The logo features a dog playing with a game
         controller. The company name 'PITBULL' is written on it."
  BAD:  "An abstract image of a dog holding a controller, and the word PITBULL on it."


1.3  Enhance Stylistic Rendering
---------------------------------
If a particular style is needed, use precise style keywords (e.g., "picture book style",
"children's book illustration style") or reference images to achieve better results.


1.4  Improve Text Rendering Accuracy
-------------------------------------
Use double quotation marks around any text that needs to appear in the generated image.

  GOOD: "Generate a poster with the title 'Seedream 4.5'."
  BAD:  "Generate a poster titled Seedream 4.5."


1.5  Define Editing Goals and Fixed Elements
---------------------------------------------
Use concise, unambiguous instructions for modifications. Avoid vague pronouns. If other
elements should remain unchanged, specify that explicitly.

  GOOD: "Dress the tallest panda in pink Peking Opera costume and headgear, keeping its
         pose unchanged."
  BAD:  "Put that one in pink clothes."


================================================================================
02  TEXT-TO-IMAGE
================================================================================

Use clear and detailed natural language to describe the scene. For complex images,
describe elements thoroughly to control the output precisely.

Prompt formula:
  [Subject + Action] + [Environment / Layout] + [Style / Color / Lighting / Composition]


2.1  Detailed Scene Description
--------------------------------
For dense, multi-element compositions, enumerate each element with its position,
appearance, and any relevant text or detail.

Example — Cluttered desk:
  "A cluttered office desk. On the desk, there is an open laptop with a screen displaying
   green code. Next to it, a mug with the word 'Developer' on it, with steam rising from
   the top. An open book lies on the desk, with pages showing a Venn diagram illustrating
   the nesting relationships of three circles in gray, blue, and light green. A sticky note
   with a mind map drawn on it, organized in a three-level vertical structure. A fountain
   pen, with the cap lying beside it. Next to the pen is a smartphone, with a new message
   notification displayed on the screen. In the corner of the desk, there is a small pot
   of succulent plants. The background is a blurred bookshelf. Sunlight shines from the
   right side, casting light and shadow on the desk."

Example — Structured spatial layout (refrigerator interior):
  "Interior view of an open refrigerator: Top shelf: On the left, there is a carton of
   milk featuring an illustration of three cows of different sizes grazing on a grassland.
   On the right, there is an egg holder containing eight eggs. Middle shelf: A plate holds
   leftover roasted chicken with a small red flag stuck into it. Next to it is a
   transparent container filled with strawberries, decorated with images of a pineapple,
   strawberries and oranges. Bottom shelf: The vegetable drawer contains lettuce, carrots
   and tomatoes. On the door shelves, there are bottles of ketchup and mayonnaise."


2.2  Knowledge & Educational Visuals
-------------------------------------
Seedream can transform knowledge and reasoning into high-density visual content such as
formulas, diagrams, and educational illustrations. Use precise technical terminology and
clearly specify the desired visualization format, layout, and style.

Example — Math on a blackboard:
  "Draw the following system of binary linear equations and the corresponding solution
   steps on the blackboard: 5x + 2y = 26; 2x - y = 5."

Example — Infographic:
  "Create an infographic showing the causes of inflation. Each cause should be presented
   independently with an icon."


================================================================================
03  IMAGE EDITING
================================================================================

Seedream supports addition, deletion, replacement, and modification of elements within an
existing image via text prompts. Use clear and concise language to indicate the target
elements and the specific changes required.


3.1  Text-Based Editing Operations
-----------------------------------

ADDITION:
  "Add matching silver earrings and a necklace to the girl in the image."

DELETION:
  "Remove the girl's hat."

REPLACEMENT:
  "Replace the largest bread man with a croissant man, keeping the action and expression
   unchanged."

MODIFICATION:
  "Turn the three robots into transparent crystal, colored red, yellow and green from left
   to right. Make the green one run, yellow walk, red stand."


3.2  Visual Indicators (Doodles, Boxes, Arrows)
------------------------------------------------
When image content is complex and difficult to describe accurately using text alone,
visual indicators drawn directly on the input image — arrows, bounding boxes, or
doodles — can specify the editing target and its location.

DOODLE example:
  "Insert a TV where the red area is marked and a sofa where the blue area is marked.
   Keep the original wooden style."

BOUNDING BOX example:
  "Enlarge the title to match the red box and change its style to match the saxophone
   icon."


================================================================================
04  REFERENCE-BASED GENERATION
================================================================================

Seedream supports extracting key information from reference images — such as character
design, artistic style, and product features — to enable tasks like character creation,
style transfer, and product design.

When using reference images, clearly describe both:
  - Reference Target: the elements to be extracted and retained (e.g., character design,
    product material, color palette).
  - Generated Scene Description: detailed information about the desired output, including
    scene, layout, and other specifics.


4.1  Reference Types
---------------------

CHARACTER reference:
  "Based on the character in the reference image, create an anime figure and place it on
   a desk. Behind it, place a birthday gift box printed with the character's image..."

STYLE reference:
  "Referencing the linear minimalist style of icons, design 9 application icons for
   different scenarios including: music, weather, calendar, camera, chat, map, alarm
   clock, shopping cart, and notebook, while maintaining a consistent color scheme."

VIRTUAL ENTITY reference:
  "Convert the character in the picture into a felt wool figure on a small stand, placed
   on a dark desk."

CLOTHING STYLE reference:
  "Generate four tops in different materials and colors, based on the clothing style worn
   by the girl in the image. Show only the clothing."


4.2  Sketches to High-Fidelity Images
--------------------------------------
For wireframes, floor plans, and hand-drawn prototypes:

  1. Provide a clear original image. If it contains text annotations, include "Generate
     based on the text in the image" in the prompt.
  2. Clarify the main subject and requirements (e.g., high-fidelity UI interface, modern
     living room).
  3. Explicitly define key consistencies with the reference, such as furniture placement
     or layout structure.

FLOOR PLAN example:
  "Based on this floor plan, generate a photorealistic image of a 'modern minimalist
   furnished living room + open dining area'. The room layout and furniture placement
   should exactly match the reference. Use a Mediterranean color palette..."

HAND-DRAWN PROTOTYPE example:
  "This is a hand-drawn wireframe of a web-based housing rental platform's detail page.
   Please render it into a high-fidelity UI interface according to the textual annotations
   in the sketch. Add sample images in the gallery section..."


================================================================================
05  MULTI-IMAGE INPUT
================================================================================

Seedream supports multi-image inputs for composite editing such as combination,
replacement, or style transfer. Clearly specify what to reference or edit from each
image, using identifiers Image 1, Image 2, ... Image N.

General formula:
  "[Action] [target element] from Image N using [reference element] from Image M, and
   generate the result in [the style of Image K]."

Example:
  "Replace the character in Image 2 with the character from Image 1, and generate the
   result in the style of Image 3."


5.1  Common Operations

REPLACEMENT:
  "Replace the subject in Image 1 with the subject from Image 2."

COMBINATION:
  "Dress the character in Image 1 with the outfit from Image 2."

STYLE TRANSFER:
  "Apply the style of Image 2 to Image 1."


================================================================================
06  MULTI-IMAGE OUTPUT
================================================================================

Seedream supports generating image sequences with consistent character continuity and
unified style, making them suitable for storyboarding, comic creation, and set-based
design scenarios — such as IP product design or emoji pack creation.

Trigger series generation by using phrases like "a series", "a set", or by specifying the
exact number of images.


6.1  Examples

BRAND VISUAL SET:
  "Refer to this logo, create a set of visual designs for an outdoor sports brand named
   'GREEN'. The products include packaging bags, hats, cards, wristbands, cartons,
   lanyards. The main visual color is green, with a simple and modern style."

FILM STORYBOARD:
  "Generate four film storyboard images, corresponding to the following scenes: astronauts
   repairing a spacecraft in a space station, suddenly encountering an asteroid belt
   attack, astronauts taking emergency evasive action, and narrowly returning to the
   spacecraft after being injured."

WALLPAPER SERIES:
  "Generate seven mobile phone wallpapers for Monday through Sunday, featuring natural
   landscapes, with each image labeled with the corresponding date."


================================================================================
QUICK REFERENCE: PROMPT TEMPLATES SUMMARY
================================================================================

Text-to-image:
  [Subject + Action] + [Environment / Layout] + [Style / Color / Lighting / Composition]

On-screen text:
  Wrap the literal text in double quotation marks: '...title "Seedream 4.5"...'

Image editing — add:
  Add [Element] to [Target] in the image.

Image editing — remove:
  Remove [Element] from the image.

Image editing — replace:
  Replace [Element] with [New Element], keeping [other attributes] unchanged.

Image editing — modify:
  Change [Element] to [New State / Color / Material / Action].

Visual indicator editing:
  [Action] where the [color] area is marked / matches the [color] box.

Reference-based generation:
  Based on the [Reference Target] from the reference image, generate [Scene Description],
  maintaining consistent [Reference Target] features.

Sketch to high-fidelity:
  Based on this [sketch type], generate a [target fidelity / style] image of [Subject].
  The [layout / placement] should exactly match the reference. Generate based on the text
  in the image.

Multi-image input:
  [Action] [Element] from Image N using [Element] from Image M, generated in the style of
  Image K.

Multi-image output:
  Generate [a series / a set / N images] of [Subject], featuring [unifying attribute],
  with each image showing [variation per image].
